# Maths Concepts

Interactive maths animations. Each concept is a single self-contained HTML page in its own folder
(`<concept>/index.html`), linked from the homepage `index.html`. No build step.

To add one: create a new folder with an `index.html`, add a "← All concepts" link to `../`,
then copy a card in the homepage grid.

Preview locally: `python3 -m http.server 8000`
